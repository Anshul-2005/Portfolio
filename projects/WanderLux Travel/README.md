# Wanderlux Travel — Luxury Travel Agency Landing Page

Premium travel agency landing page with destination cards, booking form, and testimonial carousel.

**Part of:** [Anshul Verma's Portfolio](../../index.html)

---

## 🚀 Deploy

### As Part of Portfolio (Default)
No changes needed. All paths are relative to the portfolio root.

### Standalone GitHub Pages
1. Copy this folder to a new repo
2. Enable GitHub Pages (main branch, root)
3. Update `../../index.html` links to your portfolio URL

### Standalone Netlify/Vercel
Drag and drop this folder. No build step.
